# TC-E2E-004: Multi-tenant log isolation in MaaS deployment

**Objective**: Validate end-to-end that MaaS tenants in separate
namespaces cannot access each other's inference logs through Loki,
while the platform team retains cross-namespace visibility.

**Preconditions**:
- OpenShift 4.16+ cluster with RHOAI 3.6 and MaaS deployed
- LokiStack deployed with multi-tenancy configured
- Collection pipeline routing inference logs to Loki
- Two MaaS tenants configured:
  - Tenant Alpha in namespace `tenant-alpha-ns`
  - Tenant Beta in namespace `tenant-beta-ns`
- Platform team user with cross-namespace access
- Each tenant has a deployed model processing inference requests

**Test Steps**:
1. As Tenant Alpha, send an inference request to their model
   endpoint and note a unique identifier in the prompt:
   ```bash
   curl -u alpha-user:token \
     -d '{"model":"granite-3b","prompt":"alpha-marker-2413"}' \
     http://<alpha-endpoint>/v1/completions
   ```
2. As Tenant Beta, send an inference request:
   ```bash
   curl -u beta-user:token \
     -d '{"model":"granite-3b","prompt":"beta-marker-2413"}' \
     http://<beta-endpoint>/v1/completions
   ```
3. Wait 30 seconds for log ingestion.
4. As Tenant Alpha, query Loki for all available logs:
   ```bash
   # Query as tenant-alpha-ns scoped user
   oc logs --namespace=tenant-alpha-ns -l app=loki-query
   ```
5. Verify Tenant Alpha sees logs from `tenant-alpha-ns` only.
6. Verify zero log entries from `tenant-beta-ns` are returned
   to Tenant Alpha (AC 13).
7. As the platform team user, query Loki across all namespaces.
8. Verify the platform team sees logs from both
   `tenant-alpha-ns` and `tenant-beta-ns`.

**Expected Results**:
- Tenant Alpha's Loki query returns log entries only from
  `tenant-alpha-ns` -- zero entries from `tenant-beta-ns`
- Tenant Beta's Loki query returns log entries only from
  `tenant-beta-ns` -- zero entries from `tenant-alpha-ns`
- Platform team query returns log entries from both tenant
  namespaces
- Log entries contain tenant identity and model name fields
