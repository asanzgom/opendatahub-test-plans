# TC-E2E-003: Disabled collection creates no inference-targeting resources

**Objective**: Verify disabled Monitoring CR logging does not create resources targeting
inference namespaces (AC #3).

**Preconditions**:

- Dedicated cluster with two inference namespaces and the Monitoring CR present.
- Resolve the actual logging toggle field and the selected pipeline's resource kinds and
  selectors from the sprint-zero implementation; neither is defined in the strategy.

**Test Steps**:

1. Set logging to disabled through the documented Monitoring CR field on a clean test setup.
2. Wait for a completed Monitoring CR reconciliation, then enumerate all collection resources
   for the selected pipeline (Path A or Path B) and inspect their namespace/pod selectors.
3. Send an inference request to confirm the workload remains usable.
4. If testing the transition from enabled to disabled, inspect the resources again after
   reconciliation; distinguish pre-existing unrelated resources from inference-targeting ones.

**Expected Results**:

- No newly created collection resources target either inference namespace while logging is
  disabled. Unrelated pre-existing platform collection resources do not count as failures.
- The inference request completes without depending on the logging pipeline.
